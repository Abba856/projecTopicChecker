# Project Topic Checker Using Deep Learning Algorithms

## Overview
A web-based system for students to submit project topics, using deep learning to check for similarity, sentiment, and suggest improvements. Admins can review and manage topics.

## Structure



## Abstract
This project proposes the "Design and Implementation of a Project Topic Checker Using Deep Learning Algorithms" to address challenges in academic research topic selection, such as duplicate, vague, or poorly defined submissions. The current manual review process is time-consuming and inconsistent. The proposed system aims to automate and enhance topic validation through deep learning, offering semantic similarity detection, context-aware sentiment analysis, and intelligent suggestions for students. Key objectives include detecting duplicate topics using models like BERT, analyzing topic clarity and sentiment, and generating improved topic alternatives. The system will feature a web interface for submissions, provide real-time feedback, and allow administrators to manage topics efficiently. Developed with Python (TensorFlow/PyTorch) for deep learning and integrated into a PHP-based system via a Flask/Django REST API, it will utilize MySQL for data storage. This innovation is expected to significantly reduce administrative workload, improve research topic quality, and streamline academic administration.
